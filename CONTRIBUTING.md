# Contributing

Thanks for considering an improvement to Website Image Prep.

1. Open an issue describing the bug or proposed change.
2. Keep changes focused and preserve the app's offline-first behavior.
3. Build the project and run the self-test before submitting a pull request.
4. Do not include customer images, spreadsheets, names, credentials, build products, or other private data in commits or test fixtures.

By submitting a contribution, you agree that it may be distributed under the MIT License.
